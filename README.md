# E-Commerce Sales Analysis 📊

## Project Overview

This project is an end-to-end E-Commerce Sales Analytics project focused on analyzing sales, profit, customers, products, regions, and business performance.

The project uses Excel, SQL, Python, and Power BI to transform raw sales data into meaningful insights and interactive dashboards.

> **Note:** The dataset used in this project is synthetic e-commerce data created for learning and portfolio purposes. It is not real Amazon data.

---

## 🎯 Project Objectives

- Clean and prepare the sales dataset
- Analyze sales and profit performance
- Identify top-performing products and categories
- Analyze regional and monthly sales trends
- Study customer segments and satisfaction
- Identify relationships between sales, profit, quantity, and discounts
- Detect potential sales outliers
- Create interactive dashboards for business reporting

---

## 🔄 Project Workflow

### 1. Data Cleaning – Excel

- Removed duplicate records
- Handled missing values
- Standardized date formats
- Created Year, Month and Month Name columns
- Created KPIs and PivotTables
- Built an interactive Excel dashboard

### 2. SQL Analysis

SQL was used to analyze:

- Sales and profit
- Product performance
- Category performance
- Regional performance
- Customer segments
- Monthly trends
- Business performance

### 3. Python Analysis

Python was used for Exploratory Data Analysis (EDA).

Analysis included:

- Descriptive statistics
- Correlation analysis
- Outlier detection using IQR
- Sales and profit distributions
- Category profit margins
- Product performance
- Monthly sales and profit trends

### 4. Power BI Dashboard

An interactive Power BI dashboard was created to visualize:

- Total Sales
- Total Profit
- Total Orders
- Average Order Value
- Monthly Sales Trend
- Category-wise Sales
- Product-wise Sales
- Regional Sales
- Payment Methods
- Customer Segments

---

## 📈 Key Insights

- **Total Sales:** $1,084,724.25
- **Total Profit:** $250,300.19
- **Total Orders:** 8,000
- **Average Order Value:** $135.59
- **Profit Margin:** 23.08%

Other findings:

- North America recorded the highest sales among the regions.
- Electronics was the highest-selling category.
- Office Chair generated the highest sales among products.
- December recorded the highest monthly sales and profit.
- Sales and Profit showed a strong positive correlation of approximately **0.94**.
- Quantity and Profit showed a positive correlation of approximately **0.72**.
- Discount and Profit showed a weak negative correlation of approximately **-0.10**.
- Customer Satisfaction showed very little relationship with Sales and Profit.
- IQR analysis identified **584 potential sales outliers**, which were treated as high-value transactions rather than automatically removing them.
